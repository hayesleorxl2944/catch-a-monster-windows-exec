## Frequently Asked Questions

### Is Windows the only supported platform?
Yes. The project is intended for a 64-bit desktop setup running Windows 10 or Windows 11.

### Will the executor remain compatible after Roblox updates?
Roblox client and scripting-environment changes may affect compatibility. Review the current release notes before trying a newer build.

### What makes it different from a normal Roblox launcher?
Rather than serving as a general-purpose launcher, this project is presented as a script executor that includes a script hub and toggle-based controls.

### Can script executors create account-related risks?
Third-party script tools may involve account and policy risks. Read the Roblox terms and make your own decision regarding use and responsibility.

### Are files saved on the local computer?
Because this is described as a lightweight desktop package, local files or settings may exist depending on the build and the way it is used.
